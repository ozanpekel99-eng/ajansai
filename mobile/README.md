# ajansAI mobil (Expo)

Expo SDK 58 + Expo Router. Backend: https://api.ajansai.tr (web ile aynı uçlar).

```bash
cd mobile
npm install
npx expo start          # geliştirme
npx tsc --noEmit        # tip kontrolü
```

Ekranlar: `src/app/login.tsx`, `src/app/(tabs)/` (Sohbet, Üret, Reklam, Kütüphane, Hesap).
Eski prototip `mobile-legacy/` altında (silinebilir).
